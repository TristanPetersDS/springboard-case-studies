# Introduction
This repository contains a case study examining two seperate Frequentist inference examples from the Springboard DataScience bootcamp program. 

Each part uses NumPy, Pandas, and SciPy.Stats to handle the sampling and data analysis with Matplotlib.pyplot for visualizations.

## Part A
Part A works with simulated population data examining the sampling distribution of mean heights for a city of 50,000. In this part we examine both z-testing and t-testing for sampling studying our sampling distribution.


## Part B
Part B works with real data from [Kaggle](https://www.kaggle.com/easonlai/sample-insurance-claim-prediction-dataset) to examine trends in medical charges. We also conduct hypothesis testing to determine if insured and uninsured patients are charged differently.
